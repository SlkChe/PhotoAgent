# Концепт интерфейса PhotoAgent

Спокойное рабочее пространство фотографа: светлая бумажная основа, тёмная зелёная
боковая панель, приглушённый золотой акцент. Крупный заголовок с засечками напоминает
редакционную полосу фотожурнала; элементы управления используют системный шрифт.
Внешних шрифтов, изображений и сетевых ресурсов для оформления нет.

Снимки работающего приложения: [первый экран](chat-desktop.png),
[диалог](chat-conversation.png), [мобильный экран](chat-mobile.png).

## Первый экран

- Слева: название PhotoAgent, кнопка «Новый чат», короткое описание и обозначение прототипа.
- В центре: «Хороший кадр начинается с вопроса» и четыре карточки готовых реплик.
- Внизу: закреплённое текстовое поле без загрузки файлов.
- Краткое пояснение сообщает, что в этой версии ассистент только определяет тему.

## Диалог и состояния

- Выбор карточки отправляет её пример в текущую сессию, как обычную реплику.
- После первого сообщения приветствие сменяется лентой текущего разговора.
- Ожидание сопровождается индикатором. При сбое текст остаётся доступен для повторной отправки.
- Повтор отправляет тот же идентификатор запроса; API не добавляет дубликаты в контекст.
- «Новый чат» сначала удаляет прежнюю сессию, затем создаёт пустую. Если удаление
  не удалось, интерфейс сохраняет текущий разговор и сообщает об ошибке.
- Истёкшую сессию нельзя продолжить; предлагается начать новый чат.
- После закрытия и нового открытия история не восстанавливается.

## Узкие экраны

Боковая панель сворачивается средствами Streamlit, заголовок уменьшается,
карточки перестраиваются средствами адаптивных колонок. Фокус элементов управления
видим с клавиатуры. Тексты сообщений выводятся без разрешения пользовательского HTML.
