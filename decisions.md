## Принятые решения

|---|---|---|---|
| R-01 | MVP-1 — анонимный образовательный текстовый ассистент по пяти тематикам; актуальная афиша не входит | Все участники / [цели](docs/mvp-1/purpose.md) | Соблюдать границы при реализации и разметке корпуса |
| R-02 | Анализ и планирование локальны; поиск через разрешённые адаптеры; ответ формирует одна облачная модель из конфигурации, без автоматического переключения | Backend, DevOps / [архитектура](docs/mvp-1/architect.md) | Выбрать конкретные интеграции по Q-05 |
| R-03 | Один процесс API и RAM-сессии; один диалог на профиль, защищённая cookie, TTL 12 часов бездействия; потеря RAM при рестарте допустима | Backend, frontend, DevOps / [жизненный цикл](docs/mvp-1/session-lifecycle.md) | Проверить браузерный протокол Q-01 |
| R-04 | Polling, повтор request_id и экспорт не продлевают TTL; закрытие вкладки не удаляет сессию; явная очистка отзывает доступ и отменяет выполнение | Backend, QA / [жизненный цикл](docs/mvp-1/session-lifecycle.md) | Реализовать и проверить гонки, повторы и истечение |
| R-05 | Одно выполнение на сессию; идемпотентность по (session_id, request_id), новая реплика при занятости — 409; одно уточнение на исходный запрос | Backend, frontend / [контракты](docs/mvp-1/contracts.md), [состояния](docs/mvp-1/architect.md#состояния-диалога-и-уточнения) | Завершить B-01 и оркестрацию |

| R-07 | Источники накапливаются за диалог; дедупликация только точного URL, сохраняются первый ответ и контекст; экспорт диалога и источников в Markdown | Backend, frontend / [концепция](docs/ui/concept.md), [экспорт](docs/mvp-1/session-lifecycle.md#пользовательский-экспорт) | Согласовать карточки и снимок Q-03 |
| R-08 | Статистика — дневные JSON-агрегаты за 30 дней без переписки/ID; выгрузка только владельцу, без отдельного экрана | Backend, DevOps / [статистика](docs/mvp-1/session-lifecycle.md#доступ-к-статистике) | Определить надёжность Q-02 и авторизацию Q-04 |
| R-09 | invitation — служебное приглашение без поиска, облачной генерации, оценки и учёта как содержательного ответа | Backend, frontend, QA / [Answer](docs/mvp-1/contracts.md#answer), [примеры](docs/mvp-1/contract-examples.json) | Реализовать предметные схемы 1.1 и соответствующие проверки |
