# История решений проекта

## Текущий статус проекта

Реализован прототип 0.1: FastAPI-сессии в памяти, каркас декомпозиции и четыре
обработчика-заглушки; Streamlit-чат с концептом оформления и управлением сессией.
Реальных вызовов ИИ, поиска, загрузки файлов и постоянного хранения истории нет.

## Принятые решения — 2026-09-11

| Решение | Область применения |
|---|---|
| Использовать `snake_case` для Python-модулей и каталогов импортируемых пакетов; `kebab-case` для каталогов сервисов и документов. Сохранять стандартные имена файлов инструментов. | Весь репозиторий |
| Запускать тесты через `python -m unittest discover` из корня репозитория с относительными путями и шаблоном `*_test.py`. | Тесты |
| Документировать весь HTTP API в OpenAPI: запросы, ответы, предусмотренные ошибки и фактические форматы данных. | Бэкенд |
| Кешировать в UI только допустимые повторяемые запросы чтения с TTL и ограничением размера. В первой версии ограничиться справочниками и общедоступным поиском. Историю и ответы хранить в состоянии сессии. | Streamlit UI |
| Не применять кеширование в первых версиях `core-api`. | Бэкенд |
| Передавать секреты через окружение при запуске и читать через отдельный `BaseSettings` каждого сервиса. Не хранить секреты в файлах. Для локальной отладки использовать скрытый ввод; `.env` допускается только для несекретных настроек. `st.secrets` не использовать. | Конфигурация сервисов |
| Применять профильные инструкции по затрагиваемой области независимо от роли агента. | Работа над проектом |
| «Утвердительный ответ» означает подтверждение предыдущего предложения: «да», «продолжай». | Декомпозиция запросов |
| На первом шаге использовать заменяемый классификатор по правилам. Допускать несколько тем в реплике; обработчики возвращают только названия тем. | Бэкенд 0.1 |
| Хранить контекст в памяти одного процесса API; UI хранит только копию текущего диалога для отрисовки, без восстановления после нового открытия. | Сессии 0.1 |
| Удалять сессию по «Новому чату»; при закрытии страницы пытаться отправить браузерный сигнал. Резервная очистка: TTL 180 секунд без heartbeat и проход очистки каждые 10 секунд. | Жизненный цикл сессий |
| Повторную отправку одной реплики определять по request_id; это защита от дубликатов в контексте, не кеширование запросов. | HTTP-контракт |
| TTL каждой сессии брать из `PHOTO_API_SESSION_TTL_SECONDS` (по умолчанию 180 секунд). Это скользящий TTL без активности: реплика или heartbeat продлевают `expires_at`. Предельная длительность активного разговора не устанавливается. | Настройки сессий |
| Ограничить прототип локальным запуском без авторизации: один worker API, до 1000 сессий, до 100 пар реплик на сессию и до 4000 символов в запросе. Лимиты сессий и реплик задаются окружением. | Границы прототипа |

## Проверки прототипа

- Python 3.14.7: 18 тестов `unittest` для API, хранилища сессий и Streamlit UI.
- `ruff check .`, `ruff format --check .`, `git diff --check` прошли без ошибок;
  `pip check` не обнаружил конфликтов зависимостей.
- Проверены в Chrome: реплики, «Новый чат», мобильная вёрстка и удаление при уходе со страницы.
- Команды локального запуска и отладки описаны в `README.md` и `AGENTS.md`.
- Конфигурация Ruff и Docker Compose добавлена. Docker отсутствует в текущем окружении;
  сборка и запуск контейнеров ещё не проверены.

## Завершение работы — 2026-09-11

- Локальные `core-api` и `streamlit-ui` штатно остановлены. Порты 8000 и 8501 свободны.
- Временные сессии и их контекст удалены при остановке API; это ожидаемое поведение прототипа.
- Код, правила, настройки, тесты, документация и снимки UI подготовлены к фиксации
  локальным Git-коммитом. Отправка в удалённый репозиторий не выполняется.
- Секреты для прототипа не требуются. `.env.example` содержит только безопасные настройки;
  локальные окружения Python и реальные файлы секретов в Git не включаются.
- Для продолжения активировать `source .venv/runtime-env/bin/activate` (Python 3.14.7)
  и выполнить команды запуска из `README.md`. После запуска будут созданы новые пустые сессии.
- Концепт и снимки интерфейса сохранены в `docs/ui-concept.md` и `docs/chat-*.png`.
